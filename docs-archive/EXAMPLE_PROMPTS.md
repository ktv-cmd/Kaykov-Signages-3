## Example 1: Logo Only - Coffee Shop

### Input Parameters
- **Brand Mode:** logo-only
- **Brand Text:** (not used)
- **Logo Image:** Brown coffee bean logo with cream text
- **Reference Style:** Back Lit Sign
- **Lighting Mode:** back
- **Mounting:** stand-off

### Generated Prompt

```
This is a premium architectural signage visualization for a real storefront. Image 1 shows the building with a GOLD HIGHLIGHTED ZONE — this zone (and ONLY this zone) must be replaced with the new signage. The golden yellow overlay is purely a placement guide; remove it completely in the final output. The rest of the building facade must remain exactly as photographed — preserve all original materials, textures, lighting, and architectural details outside the golden zone.  CASE A: LOGO ONLY Image 2 contains the logo artwork. Logo symbols are rendered as a 3D Light Box — a dimensional cabinet with translucent face and internal illumination. Color integrity: Use the exact HEX/Pantone colors from Image 2. This is the brand's official logo — color accuracy is critical. Lighting: Back-lit (Halo) — solid metal or acrylic faces with LEDs mounted behind the letters, creating a halo glow effect against the wall. No face illumination. Premium night presence. Mounting: stand-off mounted (depth from wall)  Result: A photorealistic 16:9 exterior shot showing the new sign seamlessly integrated into the golden zone. Premium architectural render quality.
```

### Expected Visual Result
- 3D light box featuring coffee bean symbol
- Exact brown (#8B4513) and cream (#FFF8DC) colors from logo
- Halo glow behind the sign against brick wall
- Stand-off mounting with visible studs
- No front illumination on the sign face
- Premium night-time presence with warm glow

## Prompt Anatomy Breakdown

### Core Structure (All Cases)

1. **Introduction**
   - Establishes role as premium architectural visualization
   - Defines golden zone as exclusive replacement area
   - Mandates preservation of all other pixels

2. **Case Declaration**
   - CASE A, B, or C clearly stated
   - Sets expectations for logo/text handling

3. **Construction Type**
   - Specifies 3D Light Box for logos
   - Specifies Individual Channel Letters for text
   - Exception for awning (printed application)

4. **Color Protocol**
   - Logo present: Exact color matching required
   - Text only: Contextual analysis and complementary selection

5. **Lighting Description**
   - Technical specification (LED type, placement)
   - Visual effect description (halo, glow, illumination)
   - Industry terminology

6. **Mounting Method**
   - Flush, stand-off, or raceway
   - Describes visual relationship to wall

7. **Result Specification**
   - Photorealistic 16:9 format
   - Seamless integration requirement
   - Premium quality expectation

### Variable Elements

- **brandText:** Inserted verbatim in quotes
- **reference.name:** Reference style name for context
- **reference.id:** Used to detect awning exception
- **lightMode:** Determines lighting description
- **mount:** Determines mounting description

## Testing Checklist

When validating a generated prompt:

- [ ] Case (A/B/C) correctly identified
- [ ] Construction type appropriate (light box vs channel letters)
- [ ] Color protocol matches input (exact for logo, contextual for text)
- [ ] Lighting description technically accurate
- [ ] Mounting method specified
- [ ] Golden zone replacement clearly emphasized
- [ ] Pixel preservation mandate included
- [ ] Result specification includes format and quality expectations
- [ ] No mention of golden color as brand color
- [ ] Typography guidance provided for text-only cases
